# 参考来源

## 工作流与分镜

- [Emulsion](https://github.com/dennisonbertram/emulsion)：创作者与 Agent 在同一片场协作，使用运动参考、外观图与提示词交接镜头。
- [Wonder Unit Shot Generator](https://wonderunit.com/shot-generator/)：轻量 3D 构图、人物摆位与摄影机安排。
- [Shot Designer](https://www.hollywoodcamerawork.com/shot-designer-videos.html)：走位、摄影机运动与空间布局。
- [Previs Pro](https://wiki.previspro.com/)：剧本、分镜、预演与时间轴的组织。
- [FrameForge](https://support.frameforge.com/category/31-posing-actors)：人物姿态和场景中的交互。

## 项目与文档

- [vibecoding-bip-template](https://github.com/cellinlab/vibecoding-bip-template)：项目起始模板。
- [Three.js](https://github.com/mrdoob/three.js)、[React Three Fiber](https://github.com/pmndrs/react-three-fiber)、[MCP for Blender](https://github.com/ahujasid/mcp-for-blender)：README 的快速开始、示例与接入入口组织。

详细比较见 [导演工作台调研](research/DIRECTOR-LANDSCAPE.md)、[人物调度](research/CHARACTER-DIRECTION.md) 与 [场景资产](research/SCENES-ASSETS.md)。依赖版本见 `package.json`，许可证见仓库及各项资源随附的许可声明。
