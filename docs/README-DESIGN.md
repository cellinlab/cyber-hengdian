# README 结构与配图约定

更新：2026-10-13。本文记录首页信息设计，不作为产品能力或运行验证证据。

## 采用的结构

首页按读者任务排序：理解定位 → 看真实画面 → 运行 → 完成一次工作流 → 找例子 → 接入 Agent → 扩展 → 理解边界。功能参数、实测细节和研究记录留在各自文档，首页负责入口。

本次实时读取的参考均为项目自己的仓库：

- [Three.js](https://github.com/mrdoob/three.js)：短定位、清楚的示例/文档入口，以及一个最小使用片段。采用入口清楚和尽快起步的组织方式。
- [React Three Fiber](https://github.com/pmndrs/react-three-fiber)：安装与最小场景靠前，详细教程、示例和生态链接分流。采用少量起步代码、完整说明转向专门文档的方式。
- [MCP for Blender](https://github.com/ahujasid/mcp-for-blender)：能力表、快速开始和宿主配置入口。采用按实际任务说明能力、把接入步骤单独成文的方式。

参考用于首页的信息组织；项目能力与使用说明以实际实现为准。

## 视觉约定

- 首页仅使用一张真实渲染和一张真实 UI 截图。图片展示实际结果与操作面；说明由旁边的 Markdown 完成。
- 不再嵌入此前的功能全景、比较海报或大段文字拼图。历史素材保留在仓库，不把图片删除当成 README 调整的一部分。
- 真实渲染不叠加营销标题或参数表。UI 保留自然存在的控件文字，无额外编号和文字蒙版。
- 图像需与交付版本一致，拍摄/导出/参考绑定是否完成由对应案例记录证明，图片本身不代替验证。
- 不新增群二维码。模板原作者区与原有联系/赞助资产保持不变。

## 发布前核对

图片路径为 `public/readme/truck-hero.png` 与 `public/readme/parts-director.png`。必须由真实运行提供。`docs/PARTS.md` 与 `examples/truck-parts/README.md` 对照实现和证据更新；README 不声称部件遮罩自动锁定生成模型的结构，也不声称外部生成平台已经接入。
