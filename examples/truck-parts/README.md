# 三部件卡车 / Three-part truck

本案例验证车头、车厢、车轮的标记、实际遮挡、外观图绑定和拍摄包导出恢复。

从导演台的模型库加入“厢式卡车”，或导入 [可编辑未绑定工程](truck.hengdian.json)。选中卡车，在“部件与参考”中读取网格、选择部件，再查看高亮、彩色ID与黑白遮罩。前景路灯用于检验可见表面遮挡，遮罩应保留它遮住的黑色区域。

外观图由使用者上传；示例工程不包含缺失的哈希引用。建议参考一台红色车头、银灰金属车厢、黑色轮胎的真实或生成卡车图片，分别绑定并写清各部件的用途。该图定义外观，不要求改变白模的空间关系。

导出时选择三个部件，生成拍摄包并在另一个工作空间导入。检查每个部件的遮罩、参考图及用途是否恢复。实际本轮的原始媒体、完整绑定工程及拍摄包保存在本地忽略目录；结果详见 [验证记录](../../docs/showcase/PARTS-VERIFICATION.md)。

后续视频生成须选择实际支持这些输入的模型/工作流，并另行验证边界、配色与跨帧一致性。此案例首先证明工作台的完整结构交接，不把生成服务的最终画面效果预先判为成功。
