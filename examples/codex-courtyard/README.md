# 午后交接：真实 Codex 导演案例

用自然语言搭建一段 10 秒、三镜头的庭院会面预演，再只调整第二镜头摄影机，保留场景与动作，最后导出逐镜拍摄包。

- [第一轮：搭景、走位、看图修正](01-stage.md)
- [第二轮：调整摄影机并导出](02-reframe-export.md)
- [实际完成的可编辑工程](project.hengdian.json)：可通过导演台的导入入口打开；会替换目标工作空间当前工程。
- [真实宿主的运行与验收记录](../../docs/CODEX.md)

工程 JSON 是本次模型执行的结果，作为可复用素材保存；重新执行自然语言 brief 可以产生不同导演选择。它不是测试预先注入的答案。三镜头分别为 3、4、3 秒，24fps，16:9；第二镜头的低机位调整没有改变实体、动作关键帧及另外两个镜头的摄影机。

全部角色与布景使用仓库内的程序化预演对象，无外部模型、骨骼动作或付费视频生成。这里表现的是走近、停下、即将交付的关系，不是手部抓取动画或最终电影。视频、控制通道与真实会话日志保存在本机被忽略的数据目录，不随 Git 分发。
