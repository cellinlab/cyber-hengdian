# 可复用的典型拍摄场景

两套独立的 6 秒、24fps、16:9 预演工程，用于演示空间、主体和摄影机关系如何成为视频生成的输入。全部对象来自项目内置程序化素材，不需要外部模型。

| 场景     | 预演要解决的问题                           | 可编辑工程                        |
| -------- | ------------------------------------------ | --------------------------------- |
| 静物肖像 | 产品主次、展台、留白、缓慢侧移推进         | [香水广告](product.hengdian.json) |
| 去远方   | 双人相对位置、前进路径、同速跟拍与环境透视 | [公路跟拍](road.hengdian.json)    |

在独立工作空间启动导演台，通过「导入」选择 JSON。导入会替换该工作空间当前工程；请先导出自己的作品。两套工程均只含一个镜头，可以直接导出 1280×720 拍摄包。开发者可运行 `npx tsx tools/build-showcase.ts` 从数据定义重新生成工程；脚本不调用视频生成服务。

## 交接视频的分辨率

向视频生成工具交接时，建议从工程原生导出 **1280×720** 视频，不要把 640×360 预览放大冒充高分辨率输入。640×360 仍适合本地快速检查镜头、动作与构图。

2026-10-13 的 TapNow **Seedance 2.5 视频参考模式**实测：旧庭院的 640×360 视频提交后返回 `invalid_parameters`，界面要求参考视频至少 480p。这个限制只记录当次模型与模式，不能推定为 TapNow 全平台、其他模型或后续版本的通用规格。交接前仍应确认当前界面的输入要求；本次失败保留为实测记录，没有据此自动重新发起生成。

庭院三镜头已从相同工程快照以 1280×720 逐帧重导，并合并为 10 秒、24fps、240 帧的本地参考输入。三个拍摄包的文件哈希、控制通道和视频参数均已通过校验；合并视频的尺寸、帧率、时长和帧数已由 FFprobe 核验。此项仅完成本地输入准备，不代表重新提交或生成成功。

## 向视频生成工具描述目标

使用导出的 `motion.mp4` 作为视频参考。只有所选工作流明确支持视频参考时，才能验证完整运动；仅支持图片的模式只能验证造型与构图，不能据此宣称复现了摄影机路径。下面是可直接调整的视觉转译 brief，不是生成结果或质量承诺。

### 香水广告

> 参考视频是空间与摄影机运动预演，请保留瓶体、主圆柱展台、左侧球形摆件及其辅助矮台的相对位置和画面占比，保留缓慢侧移推进的单镜头运动。把主产品转译为无品牌的高级香水瓶，烟绿色半透明玻璃、暖金属瓶颈、深绿色瓶盖、空白奶油色标签。暖灰摄影棚，柔和侧光，细腻石材展台，克制的商业静物摄影质感。6 秒，16:9，主体始终完整可见，不加文字，不新增物件，不切镜，不让瓶体自行旋转或变形。

重点核验：是否保留一瓶、主展台，以及左侧球体与辅助矮台；瓶体与背景的主次关系；侧移方向和推进幅度；瓶盖、标签与轮廓的时间一致性。

### 公路跟拍

> 参考视频是双人走位与摄影机跟拍预演，请保留两个人物、并行前进方向、相对间距和摄影机同速后退的稳定全身构图。两名成年旅行者沿乡间公路朝镜头走来，左侧赭红外套旅行者领先半步，右侧青色外套旅行者稍后，均背小型旅行背包。柔和午后自然光，远山、零散树木、旷野与道路纵深，安静的公路电影质感。6 秒，16:9，连续单镜头，全身与脚步始终可见，不增减人物，不交叉换位，不切镜，不奔跑，不生成字幕或标志。

重点核验：人数和服装归属；A/B 前后关系；双脚触地与前进方向；构图稳定与景物视差；是否把跟拍变成静态人物或无关运镜。

## 样例的真实边界

这是人工编排、经过真实 Three.js 预览与逐帧导出的预演样例，不冒充自然语言模型生成的工程。人物是简化木偶，背包随各自主体的平移轨道同步；没有骨骼穿戴、布料或物理求解。香水由基础几何组合，材质是预演材质，不是真实玻璃。TapNow 的实际模型、输入模式、生成状态与结果评价应以对应实测记录为准。
